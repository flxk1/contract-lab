# Contract Lab

An offline teaching lab for contract negotiation between two software agents. Each agent follows written rules: offer, counter-offer, acceptance, delivery and payment. Change one rule, for example the buyer's walk-away price, and watch whether a contract forms.

It is an agent-based negotiation model in which each agent is a bounded-rational expected-utility decision maker, written as explicit rules.

## Use

Download [Contract-Lab.html](Contract-Lab.html) and open it in a web browser. It runs offline, without an account, a server or an installation. Press **Start** to run the negotiation, or **Step** to advance one message at a time and ask what comes next. Open **Rule trace** to see which rule decided each step.
